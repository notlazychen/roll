# 场景
贴身小工具合集

# 功能
## 用户
- 登录、登出
- 微信登录后使用微信头像和微信昵称
- 所有功能登录后才能使用
- 登出后原界面清理

## 界面
- 整体布局分主界面和底栏两部分
- 底栏有以下几项，每项对应一个页面
    + 明细。直接列表展示最近的账目。
    + 图表。展示周、月、年的图表。
    + 我的。个人信息、设置、选项管理。

## 记账
每一条账目都有的属性：
- 收入、支出
- 金额
- 分类（餐饮、住宿、出行、购物）
- 渠道（比如餐饮可以是KFC、麦当劳等等，购物可以是淘宝、京东、万达广场XX店等等）
- 交易时间
- 记录时间
- 消费者，集合（比如给谁谁谁消费的）
- 备注
- 标签，通过备注分析出来的标签
- 所属账户（支付宝、微信、银行等）

## 报表
- 可以查看指定时间段的收入、支出总额
- 分类报表，展示饼图
- 月报表出示每日收入、支出折线图

### 关于选项源
- 分类、取到、消费者都是有选项的。
- 其中一些属性的选项是预设的，但预设肯定不够用，也要支持用户动态增加，加到选项源里。后面也可以维护。
- 一个已经被用过的选项源项是不能删除的。
